# SPICELAND — LOADER DROPS SPEC

## Что нужно сделать

Создать три анимируемые капли для загрузочной анимации сайта SpiceLand:

1. Красную.
2. Зелёную.
3. Золотисто-оранжевую.

Капли должны лететь с разных сторон, вращаться, слегка растягиваться и сжиматься, закручиваться в вихре, сталкиваться и попадать в соответствующие части логотипа.

---

## 1. Этот файл

```text
После этого реализуй:
1. Один универсальный SVG-компонент капли.
2. Три экземпляра: красный, зелёный и золотисто-оранжевый.
3. Состояния: idle, flying, vortex и impact.
4. Полёт, вращение, растяжение, сжатие и столкновение.
5. Попадание каждой капли в свою часть логотипа.
6. Переход логотипа из серого состояния в цветное.
7. Плавное появление Hero Section после анимации.

Используй SVG, SVG mask или clipPath, GSAP либо другой надёжный способ морфинга, SCSS, BEM и компонентную архитектуру.

Не создавай три копии логики.
Должен быть один универсальный компонент и три набора данных.
```

Один компонент:


```js
{
  id: "red-drop",
  color: "#e11f21",
  texture: "assets/textures/drop-red.webp",
  startX: 0,
  startY: 0,
  delay: 0,
  target: "logo-red-zone"
```

# Внешний вид капель

Каждая капля должна иметь:

- полупрозрачную жидкую текстуру;
- внутреннюю глубину;
- статичный блик сверху слева;
- мягкое внутреннее свечение;
- аккуратный край;
- прозрачный фон;
- без мелких лишних капель вокруг.

Цвета:

```scss
$drop-red: #e11f21;
$drop-green: #6ea52b;
$drop-gold: #ff9100;
```

# Состояния капли

## Idle

- спокойная;
- симметричная;
- слегка «дышит»;
- немного покачивается.

## Flying

- вытягивается по направлению движения;
- немного сжимается поперёк;
- слегка колеблется;
- сохраняет блик внутри формы.

## Vortex

- вращается по круговой траектории;
- слегка вытягивается от скорости;
- не выглядит как обычная картинка, которую просто вращают.

## Impact

- сплющивается;
- расширяется;
- даёт короткий пружинящий эффект;
- затем направляется в свою часть логотипа.

---

# Анимация логотипа

Начальное состояние:

- серый;
- без свечения;
- без движения.

После попадания капель:

1. Красная капля окрашивает красную часть.
2. Зелёная капля окрашивает зелёную часть.
3. Золотистая капля окрашивает золотистую часть.
4. Логотип становится цветным.
5. По контуру проходит световое кольцо.
6. Появляется мягкое свечение.
7. Логотип начинает очень медленное 3D-вращение.
8. Hero Section плавно появляется.

# Технические правила

- PNG/WebP используется как внутренняя текстура.
- Деформируется SVG-форма.
- Блик должен оставаться внутри SVG-маски.
- Использовать transform, opacity и SVG path morphing.
- Не анимировать постоянно top и left.
- Поддержать prefers-reduced-motion.
- Для слабых устройств сделать упрощённый режим.
- На мобильных анимация должна быть легче и короче.
