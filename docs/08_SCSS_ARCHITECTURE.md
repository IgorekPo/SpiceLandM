# SCSS ARCHITECTURE

- `abstracts` — дизайн-токены, контрольные точки и миксины без самостоятельного CSS-вывода.
- `base` — reset, глобальные правила и типографика.
- `layout` — контейнер, Header и общий каркас.
- `components` — переиспользуемые кнопки, карточки и другие UI-блоки.
- `sections` — уникальные секции страниц.
- `main.scss` — единая точка подключения модулей через `@use`.

Цвета и повторяемые размеры брать из переменных. Адаптив писать mobile-first через миксины с `min-width`.
