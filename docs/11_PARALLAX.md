# PARALLAX

Hero складається з трьох незалежних растрових шарів:

1. Далекий — темна фактурна поверхня, пил і дрібні спеції.
2. Середній — листя, червоний перець і горошини спецій на прозорому фоні.
3. Передній — великі часник, перець і листя по краях на прозорому фоні.

Шари рухаються з різною інтенсивністю через GSAP. Основний контент, Header і логотип не рухаються разом із паралаксом.

Блок `catalog-preview` також використовує по три незалежні шари для кожної категорії:

1. `far` — озеро та гори для рідких маринадів або ліс для сухих;
2. `middle` — альтанка або зона барбекю на прозорому фоні;
3. `front` — стіл, готова страва та гриль на прозорому фоні.

На desktop шари реагують на положення вказівника через GSAP із різною силою. На touch-пристроях зберігається м’який автономний рух. Відблиски води та дим анімовані окремо; текст і кнопки не входять до паралакс-шарів.
