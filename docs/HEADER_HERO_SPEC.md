# SPICELAND — HEADER, HERO ТА ВСТУПНА АНІМАЦІЯ

## Призначення документа
Цей файл є технічним завданням для реалізації:
1. Вступної анімації завантаження.
2. Фіксованого Header.
3. Hero Section.
4. Модального вікна «Залишити заявку».
5. Модального вікна подяки.
6. Адаптації для desktop, tablet і mobile.

Усі написи сайту мають бути українською мовою.

# 1. Загальна концепція

Перший екран має викликати:
- довіру;
- відчуття європейської якості;
- преміальність без пафосу;
- спокій;
- бажання продовжити перегляд.

Hero відтворює затверджену темну гастрономічну композицію з референса. Спеції, листя, перець і часник використовуються контрольовано та розподіляються між трьома паралакс-шарами без перекриття основного контенту.

Головні акценти:
- оригінальний логотип SpiceLand;
- атмосферний природний фон;
- чиста композиція;
- дві основні дії користувача;
- фірмова вступна анімація.

# 2. Фірмові кольори

```scss
$color-dark: #403536;
$color-orange: #ff9100;
$color-red: #e11f21;
$color-white: #ffffff;
```

Правила:
- корпоративні кольори використовуються у кнопках, текстових акцентах, іконках, рамках та логотипі;
- усі активні кнопки та посилання у вигляді кнопок при наведенні за `0.5s` заповнюються зліва направо кольором `#FF9100`, а текст стає `#403536`;
- природний фон не фарбується корпоративним фільтром;
- природа повинна виглядати живою, свіжою та реалістичною;
- зелений використовується для успішної валідації;
- червоний — для помилки.

# 3. Вступна анімація

## 3.1. Загальна логіка

Анімація запускається при кожному відкритті сайту.

Поки вона відтворюється, браузер паралельно завантажує:
- фонові зображення;
- Hero;
- логотип;
- шрифти;
- ресурси наступних секцій.

Орієнтовна загальна тривалість: 5–7 секунд, включно з трисекундною фазою вльоту крапель, зіткненням, оживленням логотипа та проявленням Hero.

## 3.2. Початковий стан

Оригінальний логотип SpiceLand розташований у точній фінальній позиції Hero-логотипа: по центру екрана по горизонталі, а його верхній край — на `20px` нижче нижньої межі Header. Розмір також повністю збігається з фінальним Hero-логотипом на кожному адаптивному брейкпоінті:
- без тексту поруч;
- у сірому або чорно-білому вигляді;
- без світіння;
- без обертання;
- візуально «неживий».

Використовувати лише оригінальний файл логотипа без перемальовування.

Рекомендований шлях:

```text
assets/logos/logo.svg
```

## 3.3. Три маринади

З різних сторін екрана влітають три рідкі маринади:
- червоний;
- зелений;
- жовто-помаранчевий / світло-коричневий згідно з логотипом.

Кожен маринад має вигляд живої рідини, а не геометричної фігури.

Базова форма кожного маринаду — округла об’ємна крапля з коротким витягнутим хвостом, спрямованим проти напрямку руху.

Під час усього руху кожна крапля безперервно деформується та звивається подібно до змії. Статичне переміщення незмінного силуету заборонене. Деформація реалізується через GSAP-комбінацію `skew`, нерівномірного `scale` і зміщень внутрішнього шару краплі без анімованого обертання.

Растрові зображення маринадів повинні мати справжній прозорий alpha-фон. Чорний прямокутний фон у файлі або навколо потоку заборонений.

## 3.4. Послідовність анімації

1. Три краплі влітають з різних боків і летять точно назустріч одна одній.
2. Краплі плавно прискорюються без обертання навколо спільної осі та без утворення вихору.
3. Краплі стикаються над сірим логотипом.
4. У момент зіткнення утворюється короткий рідкий сплеск.
5. Після зіткнення кожна з трьох крапель різко зменшується.
6. Маленькі краплі падають на відповідні кольорові частини логотипа.
7. Логотип поступово набуває фірмових кольорів у тій самій позиції та без геометричного стрибка.
8. З’являється м’яке тепле світіння без золотого кільця навколо логотипа.
9. Після оживлення логотип починає плавно обертатися у 3D; багатошарова кромка додає йому товщини та не дозволяє зникати у положенні ребром.
10. Від логотипа розходяться ледь помітні хвилі.
11. Разом із хвилями проявляється Hero Section.

Фаза вльоту та зближення трьох крапель триває рівно `3s`; зміна виконується таймлайном GSAP.

## 3.5. Технічні вимоги

Дозволено:
- SVG;
- CSS transforms;
- Canvas;
- GSAP;
- SVG masks та filters.

Не використовувати `top` і `left` для постійної анімації.

Основні властивості:
- `transform`;
- `opacity`;
- `filter`;
- `clip-path`.

Потрібна підтримка:
- desktop;
- Android;
- iPhone;
- tablet.

Передбачити:
- спрощену версію для слабких пристроїв;
- `prefers-reduced-motion`.

# 4. Header

## 4.1. Структура

Header завжди закріплений зверху.

Фон Header займає всю ширину екрана. Внутрішній контент Header обмежений спільним контейнером `1440px` і має мінімальні відступи `2px` зліва та справа.

Склад:

### Ліва частина
- повний оригінальний логотип SpiceLand: круглий знак разом із фірмовим написом;
- обрізати напис або показувати у Header лише круглу частину SVG заборонено;
- клік по логотипу плавно повертає до Hero.

### Права частина
1. Номер телефону.
2. Кнопка «Залишити заявку».
3. Кнопка «Контакти» на desktop.
4. Burger button на tablet і mobile.

Кнопка «Залишити заявку» відображається на всіх ширинах без винятків, включно з мінімальною шириною `320px`.

Відстань між елементами `header__actions` на mobile і tablet — `14px`.

## 4.2. Стиль

Header зберігає композицію з наданого макета, але стає легшим.

Стиль:
- glassmorphism;
- напівпрозорий матовий фон;
- розмиття фону Header: `backdrop-filter: blur(4px)`;
- легке розмиття;
- тонка рамка;
- мінімальна тінь;
- невелика висота;
- не забирає увагу у Hero.

Приклад:

```scss
background: rgba(64, 53, 54, 0.24);
border: 1px solid rgba(255, 255, 255, 0.16);
backdrop-filter: blur(4px);
-webkit-backdrop-filter: blur(4px);
```

Орієнтовна висота:
- desktop: 72–80 px;
- tablet: 68–74 px;
- mobile: 60–68 px.

## 4.3. Телефон

Формат:

```text
+38 (0XX) XXX-XX-XX
```

На мобільному використовувати `tel:`.

Hover телефону:
- фон посилання не змінюється;
- лише іконка та цифри заповнюються кольором `#FF9100` зліва направо;
- тривалість заповнення — `0.5s`.

## 4.4. Кнопка «Залишити заявку»

Стиль:
- прозорий або напівпрозорий фон;
- дуже тонкий білий border;
- менша висота;
- акуратні горизонтальні відступи;
- без важких тіней.

Hover:
- фон плавно заповнюється;
- текст змінює контрастний колір;
- без різкого масштабування.

## 4.5. Burger menu

При відкритті:
- body отримує `overflow: hidden`;
- сторінка не прокручується;
- фон затемнюється і розмивається;
- після вибору пункту меню воно закривається;
- виконується плавний перехід до секції.

Пункти:
- Головна;
- Про компанію;
- Наші маринади;
- Каталог;
- Чому обирають SpiceLand;
- Контакти.

Візуальна ідея:
- ліва частина — рідкий маринад;
- права частина — сухий маринад;
- обидві частини ніби стикаються;
- точний дизайн буде розроблений пізніше.

# 5. Hero Section

## 5.1. Розмір

```scss
min-height: 100vh;
min-height: 100dvh;
```

Hero плавно проявляється після вступної анімації.

## 5.2. Фонове зображення

Фон має точно наслідувати затверджений референс:
- темна фактурна кам’яна або ґрунтова поверхня;
- глибокий чорний фон;
- тепле бурштинове контрове світло;
- розсипані частинки спецій;
- преміальна food-photography атмосфера;
- центральна та права зони зберігають достатній контраст для білого тексту;
- без пляшок, упаковки, написів і сторонніх логотипів.

Корпоративний коричневий фільтр поверх зображення не накладається: темна палітра формується самим освітленням сцени.

## 5.3. Паралакс Hero

Hero має три декоративні шари.

Основний контент не рухається.

### Далекий шар
- темна фактурна поверхня;
- пил спецій і дрібне насіння;
- тепле локальне світло;
- максимальна глибина різкості.

### Середній шар
- зелене листя;
- червоний перець;
- горошини перцю;
- дрібні частинки спецій;
- об’єкти середнього масштабу.

### Передній шар
- великі зубчики та головка часнику;
- сушений червоний перець;
- темне листя;
- великі частинки по краях кадру;
- центральна зона залишається вільною.

Архітектура та наповнення трьох шарів затверджені на основі наданого референса.

## 5.4. Логотип у Hero

- оригінальний;
- по центру екрана по горизонталі у верхній частині Hero;
- верхній край логотипа розташований на `20px` нижче нижньої межі Header;
- без тексту поруч;
- круглий;
- після оживлення повільно обертається у 3D;
- має багатошарову об’ємну кромку без зміни оригінального SVG, тому не виглядає плоским і не зникає у положенні ребром;
- має м’яке світіння після loader-анімації.

## 5.5. Композиція

### Права частина
Приблизно 55–60% композиції:
- коротке привітання;
- назва компанії;
- позиціонування;
- короткий опис.

Чернетка:

```text
Вас вітає компанія SpiceLand

Імпортер преміальних рідких та сухих маринадів із Європи.

Ми постачаємо професійні маринади з Німеччини, Франції та Нідерландів.
```

Фінальний текст буде погоджено окремо.

### Ліва частина
Дві кнопки:
1. «Перейти до каталогу».
2. «Зворотний зв’язок».

«Перейти до каталогу» веде до секції вибору:
- рідкі;
- сухі;
- загальний каталог.

«Зворотний зв’язок» відкриває форму заявки.

## 5.6. Кнопки Hero

Розташування:
- mobile: дві вертикальні кнопки шириною `260px`, вирівняні по центру;
- tablet: нижній внутрішній відступ Hero збільшений на `40px` відносно попереднього значення;
- desktop: блок кнопок знаходиться в лівому нижньому куті внутрішнього контейнера з відступом `60px` зліва та `140px` знизу.

Стиль:
- прозорий фон;
- дуже тонка біла рамка;
- білий текст;
- невелика висота;
- акуратний радіус;
- без важких тіней.

Hover:
- фон за `0.5s` плавно заповнюється зліва направо кольором `#FF9100`;
- текст стає `#403536`;
- правило однакове для всіх активних кнопок сайту.

# 6. Модальне вікно «Залишити заявку»

## 6.1. Розташування

- прямокутне;
- по центру;
- поверх усіх секцій;
- фон затемнюється і розмивається;
- прокрутка блокується.

## 6.2. Поля

Тільки два обов’язкові поля.

### Телефон
- `+38` показано постійно;
- користувач не може його видалити;
- після `+38` перша цифра обов’язково `0`;
- після `+38` вводиться рівно 10 цифр;
- лише цифри;
- автоматичне форматування.

Приклад:

```text
+38 0XX XXX XX XX
```

### Область
- обов’язкове поле;
- мінімум одна літера;
- лише цифри або пробіли не вважаються валідними.

## 6.3. Валідація

Коли поле активне:
- border зелений.

Після переходу до іншого поля:
- валідне поле залишається зеленим;
- невалідне стає червоним.

Кнопка неактивна, доки:
- телефон не заповнено;
- область не містить хоча б одну літеру.

Текст кнопки:

```text
Відправити запит
```

## 6.4. Надсилання

Після успішного надсилання:
- дані відправляються у Telegram-групу менеджерів;
- форма закривається;
- з’являється модальне вікно подяки.

Telegram реалізується окремим модулем.

# 8. Адаптивність

## Desktop
- повна композиція;
- логотип по центру зверху, на `20px` нижче Header;

## Mobile
- текст коротший;
- вертикальна композиція;

- паралакс від нахилу пристрою;
- для iPhone запит дозволу на `DeviceOrientationEvent`;
- без дозволу — резервна легка анімація без помилок.

# 10. Обов’язкові правила

- SCSS.
- BEM.
- Один логічний блок — один компонент.
- Зрозумілі назви файлів, змінних, міксинів і функцій.
- Повторювані значення — у SCSS variables.
- Не дублювати код.
- Не переписувати робочі компоненти без потреби.
- Інтерфейс українською.
- Оригінальний логотип не змінювати.
- Контент не рухається разом із паралаксом.
- Фон і три шари відтворюють затверджену темну гастрономічну композицію.
- Корпоративні кольори — лише UI-акценти.
- Якість важливіша за кількість ефектів.
- Кожна анімація повинна мати мету.
- Перевірити desktop, tablet і mobile.
