
# CATALOG_PREVIEW_SPEC.md
# SpiceLand — Технічна специфікація блоку «Вибір категорії маринадів»

> Версія: 1.0

## Призначення
Блок є переходом між головною сторінкою та каталогом. Його задача — не просто дати вибір, а створити відчуття входу в атмосферу відповідної категорії.

---

# Desktop

Екран поділений на дві великі сцени.

## Ліва сцена
- Рідкі маринади
- Заголовок
- Короткий опис
- Список переваг
- Кнопка «Рідкі маринади» без стрілки

## Права сцена
- Сухі маринади
- Заголовок
- Короткий опис
- Список переваг
- Кнопка «Сухі маринади» без стрілки

## Нижня кнопка
По центру:
- «Всі маринади» без стрілки
- Кнопки вибору компактні, мають горизонтальні внутрішні відступи по `20px`.
- На desktop і laptop заголовок категорії та опис розташовані зверху ліворуч із відступом `10px` від Header; eyebrow — зверху праворуч, а три переваги — під ним.

---

# Tablet

Композиція:
- зверху — рідкі маринади;
- знизу — сухі маринади.

---

# Mobile

Дві окремі картки зі свайпом.

Кожна картка містить:
- кнопку переходу до власного каталогу;
- кнопку переходу до загального каталогу.

Підтримати інерційний swipe.

---

# Анімація переходу

Після натискання:
1. Сцена плавно масштабується.
2. Камера ніби входить усередину пейзажу.
3. Після завершення відкривається каталог.

Повернення назад виконується аналогічною анімацією віддалення.

До появи карток каталогу використовується лише фон із трьома шарами.

---

# Паралакс

## Рідкі маринади

Далекий шар:
- озеро;
- гори;
- зелений ліс;
- легкі відблиски на воді.

Середній шар:
- альтанка.

Передній шар:
- світлий дерев'яний стіл;
- готова страва;
- мангал.

Додатково:
- легке коливання листя;
- слабкі відблиски на воді.

## Сухі маринади

Далекий шар:
- зелений ліс.

Середній шар:
- зона барбекю.

Передній шар:
- світлий стіл;
- готовий шашлик.

Додатково:
- дим постійно плавно коливається.

---

# Правила реалізму

Не допускається:
- однаковий розмір шматків м'яса;
- однакова прожарка;
- штучна симетрія.

М'ясо повинно виглядати натурально.

---

# Коригування референсу

Прибрати:
- відро рідкого маринаду;
- пакет сухого маринаду.

Залишити:
- природу;
- атмосферу;
- готові страви.

Корпоративні кольори використовуються лише в інтерфейсі.

---

# Референсні зображення

До документа додано два історичні референси:
- Liquid Catalog Reference
- Dry Catalog Reference

Вони зберігаються лише як орієнтир для майбутнього окремого етапу створення нових фонів. У поточній реалізації заборонено відновлювати з них фотографії, об'єкти або тришарові сцени без нового затвердження.

---

# Поточний етап реалізації

- Зберегти блок вибору категорії, вхід до каталогу та повернення.
- Не використовувати фонові фотографії, паралакс-шари, воду, дим або пов’язані з ними ефекти.
- Нові фони будуть створені окремим наступним етапом після затвердження.

---

# Статус реалізації — 2026-08-04

- Усі копії попередніх шести raster assets рідкої та сухої сцен повністю видалено з проєкту.
- У `catalog-preview` та fullscreen-каталозі немає `far / middle / front`, паралаксу, води, диму й коду керування цими ефектами.
- До створення нових затверджених фонів обидві сцени використовують нейтральну суцільну темну підкладку.
- Списки переваг з іконками завжди вирівнюються по лівому краю контентної області. Кнопка переходу до відповідної категорії центрується в межах своєї сцени та розташовується на `40px` вище попередньої нижньої позиції.
- Кнопки «Рідкі маринади», «Сухі маринади» та «Всі маринади» мають горизонтальні відступи `48px`.
- Кнопка категорії у кожній сцені має ширину `30%` від свого батьківського блоку на tablet/desktop. На mobile обидві кнопки всередині кожної сцени мають однакову ширину `70%`.
- На desktop список переваг з іконками розташовується зліва безпосередньо під описом категорії; eyebrow залишається у правому верхньому куті.
- Блок вибору категорії реалізовано як окрему секцію `catalog-preview`.
- Секція завжди має точну висоту видимої області (`100dvh`) без збільшення сторінки або обрізання контенту.
- На desktop рідка й суха сцени займають відповідно ліву та праву половини всієї ширини viewport; зміст залишається в центральній зоні максимум `1440px`.
- Desktop: дві рівні сцени поруч; tablet: сцени одна під одною; mobile: дві swipe-картки з інерційним `scroll-snap`.
- Desktop-перехід до каталогу й повернення зберігають легку GSAP-анімацію контейнера без фонових шарів. На mobile/tablet використовується простий CSS opacity transition.
- Fullscreen-каталог і універсальні картки товарів реалізовано окремими компонентами; їхній JavaScript підвантажується лише перед першим відкриттям каталогу.
