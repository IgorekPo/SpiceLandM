# BEM RULES

- Использовать схему `.block`, `.block__element`, `.block--modifier`.
- Не создавать элементы элементов: вместо `.block__item__icon` использовать `.block__item-icon`.
- Модификатор не используется без базового класса.
- JavaScript-хуки задавать через `data-*`, не привязывать логику к оформлению.
- Не использовать идентификаторы для CSS-стилей.
- Вложенность SCSS должна отражать один BEM-блок и не создавать избыточную специфичность.
