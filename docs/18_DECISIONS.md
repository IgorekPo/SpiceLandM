# DECISIONS

## 2026-08-03

- Выбран Vite как сборщик проекта.
- Выбран GSAP как основная библиотека анимаций.
- Утверждён подход mobile-first с поддержкой экранов от 320px до 1920px и более.
- Для каждой секции без исключений утверждена полноширинная оболочка фона и внутренний контейнер всего контента: максимум `1440px`, отступы от краёв экрана по `2px`.
- Фоны всех блоков, включая Header, всегда полноширинные.
- Серый логотип loader и цветной логотип Hero всегда располагаются в одной адаптивной позиции и одном размере: по центру сверху, на `20px` ниже Header.
- Объёмные капли вступительной анимации имеют прозрачный фон, непрерывно деформируются через GSAP transforms и летят навстречу друг другу ровно `3s`.
- Утверждена последовательность loader: встречный полёт → столкновение → уменьшение → падение на логотип → оживление логотипа и проявление Hero.
- Капли не вращаются; после оживления Hero-логотип постоянно и плавно вращается в 3D, а многослойная кромка создаёт видимую толщину без изменения оригинального SVG.
- Hover всех активных кнопок унифицирован: заливка `#FF9100` движется слева направо `0.5s`, текст меняется на `#403536`.
- Desktop-кнопки Hero располагаются внутри контейнера с отступами `60px` слева и `140px` снизу.
- В Header используется оригинальный SVG целиком — круглый знак и фирменная надпись; кадрирование до одного круга запрещено.
- Для `catalog-preview` утверждены две независимые трёхслойные сцены без упаковки: озеро/альтанка/готовое блюдо для жидких маринадов и лес/мангал/готовое блюдо для сухих.
- На mobile категории выбираются инерционным горизонтальным swipe, на tablet располагаются вертикально, на desktop — двумя равными колонками.
- Пока карточки каталога не разработаны, кнопки открывают только полноэкранный трёхслойный фон с GSAP-анимацией входа и возврата; фиктивные карточки не создаются.
