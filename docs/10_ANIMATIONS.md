# ANIMATIONS

- Основная библиотека анимаций — GSAP.
- Анимация усиливает иерархию и ощущение качества, но не мешает чтению и взаимодействию.
- Для появления элементов использовать мягкие смещения и прозрачность без резких эффектов.
- Обязательно учитывать `prefers-reduced-motion: reduce`: сложные анимации отключаются, контент остаётся доступным.
- Интерактивные состояния CSS допускаются для простых hover/focus-переходов.
- Hover всех активных кнопок длится `0.5s`: фон заполняется цветом `#FF9100` слева направо, текст меняется на `#403536`.
