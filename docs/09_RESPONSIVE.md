# RESPONSIVE

## Основной принцип

Все стили пишутся по системе mobile-first: базовые правила предназначены для экранов от 320px, расширения добавляются через `min-width`.

## Контрольные точки

- 320px — минимальная поддерживаемая ширина.
- 480px — большие мобильные устройства.
- 768px — планшеты.
- 1024px — ноутбуки и горизонтальные планшеты.
- 1280px — стандартные desktop-экраны.
- 1600px — широкие экраны.
- 1920px — сверхширокие экраны.

Контрольные точки применяются только там, где компоненту действительно требуется изменение. Запрещено строить основную адаптацию через `max-width`.

Контент должен сохранять читаемую ширину на больших экранах, а декоративные элементы могут масштабироваться с помощью `clamp()`.

## Контейнеры и фон

- Это правило обязательно для всех секций проекта без исключений.
- Каждая секция имеет полноширинную внешнюю оболочку для фона и отдельный внутренний `.container` для всего контента.
- Максимальная ширина `.container` и находящегося в нём контента — `1440px`.
- На узких экранах ширина контейнера рассчитывается как `100% - 4px`, что гарантирует отступ по `2px` с каждой стороны.
- Фоны секций, Header и декоративные полноэкранные слои не ограничиваются контейнером и всегда занимают `100%` ширины экрана.
