# PROJECT RULES

- Использовать SCSS, BEM и компонентную архитектуру.
- Интерфейс и пользовательский контент писать на украинском языке.
- Сборка проекта выполняется через Vite.
- Анимации реализовывать через GSAP.
- Вёрстку и стили создавать по принципу mobile-first.
- Минимальная поддерживаемая ширина экрана — 320px.
- Интерфейс должен корректно масштабироваться до сверхшироких экранов.
- Каждая секция без исключений должна состоять из полноширинной оболочки и внутреннего контейнера контента.
- Максимальная ширина внутреннего контейнера и всего контента каждой секции — `1440px`.
- Пока ширина экрана меньше максимального контейнера, между контентом и каждым краем экрана обязательно оставляется по `2px`.
- Фон каждой секции, включая фон Header, всегда занимает всю ширину экрана и не ограничивается контейнером `1440px`.
- Текст, кнопки, навигация, карточки и остальные смысловые элементы должны находиться внутри общего контейнера `1440px`.
- Компонентные классы секций не должны переопределять ширину общего `.container` значением `width: 100%` или другим полноширинным значением.
- При наведении все активные кнопки и ссылки, визуально оформленные как кнопки, за `0.5s` плавно заполняются слева направо цветом `#FF9100`; цвет текста одновременно меняется на `#403536`.
- Документация имеет приоритет при принятии проектных решений.
